# NexSale-B2B

**English** · [Español](README.es.md)

> 🚧 **Work in progress.** Authentication and the core product and order flows already work; some endpoints are still being implemented (see [Roadmap](#roadmap)).

Transactional backend for managing B2B orders and sales. A REST API built with **FastAPI** that handles users with different roles, a product catalogue with stock control, customer orders and invoice generation, all deployed with **Docker Compose** behind an **Apache** reverse proxy.

Developed for the *Advanced Programming Techniques* course.

## Features

- **JWT authentication** (OAuth2 password flow) with 8-hour sessions.
- **Role-based access control** with three roles:

  | Role | Permissions |
  |---|---|
  | `admin` | Everything, including deleting orders |
  | `commercial` | Create orders and browse the catalogue |
  | `warehouse` | Manage products, stock and product images |

- **Product catalogue**: create products, sortable listing, upload and download product images.
- **Orders**: orders with several line items, automatic stock checks and stock reduction, total calculation and customer tax ID validation (Croatian OIB).
- **Invoices**: download any order as a **PDF** or **RTF** invoice. Concurrent report generation is limited with a semaphore.
- **Password storage** with a per-user salt and a global pepper.
- **Web portal**: a lightweight HTML frontend (login and order management) served by Apache.
- **Interactive API docs** generated by FastAPI at `/docs` and `/redoc`.

## Tech stack

| Layer | Technology |
|---|---|
| API | Python 3.11, FastAPI, Pydantic, Uvicorn |
| Persistence | SQLAlchemy 2, MySQL 8 (PyMySQL) |
| Security | PyJWT, salted and peppered password hashing |
| Reports | fpdf2 (PDF), RTF |
| Infrastructure | Docker, Docker Compose, Apache httpd 2.4 (reverse proxy) |

## Architecture

```text
            ┌──────────────────────────── nexsale_net ────────────────────────────┐
 Browser ──►│  Apache :80  ──(/auth, /products, /orders, /docs)──►  FastAPI :8000 │
            │     │                                                    │          │
            │     └── serves frontend/index.html                       ▼          │
            │                                                     MySQL :3306     │
            └─────────────────────────────────────────────────────────────────────┘
```

The code is organised in layers:

```text
server/
├── main.py          Entry point and router registration
├── routers/         HTTP endpoints (auth, products, orders)
├── services/        Business logic (orders, stock, reports, auth)
├── schemas/         Pydantic validation and response models
├── models.py        SQLAlchemy ORM models
├── api/deps.py      Dependencies: current user, RoleChecker
└── core/            Configuration and security (hashing, JWT)
frontend/            Static web portal
apache/              Reverse proxy image and virtual host
scripts/             Initial database seeding
```

## Getting started

**Requirements:** Docker and Docker Compose.

1. Clone the repository:

   ```bash
   git clone https://github.com/enekorodriguezg/NexSale-B2B.git
   cd NexSale-B2B
   ```

2. Create the environment file and fill in every value:

   ```bash
   cp .env.example .env
   ```

   | Variable | Description |
   |---|---|
   | `MYSQL_ROOT_PASSWORD`, `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD` | MySQL credentials |
   | `MYSQL_PORT` | Host port where MySQL is exposed |
   | `PEPPER` | Secret added to every password before hashing |
   | `SECRET_KEY` | Key used to sign JWTs |

3. Build and start the services:

   ```bash
   docker compose up --build
   ```

4. Open:
   - Web portal: <http://localhost>
   - API docs: <http://localhost/docs>

On startup the API creates the tables and seeds three demo users (`admin`, `user_com`, `user_ware`) defined in `scripts/seed_users.py`. **They are for local development only**: change their credentials before deploying anywhere else.

## API overview

| Method | Endpoint | Roles |
|---|---|---|
| `POST` | `/auth/login` | public |
| `GET` | `/auth/me` | any authenticated user |
| `GET` | `/products` | all |
| `POST` | `/products` | admin, warehouse |
| `PUT` / `GET` | `/products/{id}/image` | admin, warehouse / all |
| `POST` | `/orders` | admin, commercial |
| `GET` | `/orders` | all |
| `DELETE` | `/orders/{id}` | admin |
| `GET` | `/orders/{id}/report?format=pdf\|rtf` | public (see [Roadmap](#roadmap)) |
| `GET` | `/health` | public |
